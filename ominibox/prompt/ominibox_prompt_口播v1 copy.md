## 0. 产品速览（官网归纳）

**小黑 OmniBox：你的 AI 知识伙伴。** 口号「随时随地 · 万物变成记忆 · 记忆变成万物」。
一句话：记录、收藏、订阅、整理、问答、创作、分享、协作，一个就够了。

| 环节 | 官网标题 | 能力 |
|---|---|---|
| 记录 | 随时随地 | 不改变习惯，把内容随手交给小黑：**微信 / QQ 聊天助手**（转发文字、语音、图片、文件、链接）、**随手记**（文字、录音、照片、链接）、**浏览器插件**（整页、选区、社交内容、在线视频）、**RSS 订阅**（博客、新闻、播客自动入库） |
| 理解 | 万物变成记忆 | 不只存文件，而是理解内容：**网页**→可编辑、可追溯的文档；**文档**（PDF / Word / PPT）→可搜索的知识；**图片**→扫描件 OCR、照片生成语义摘要；**音视频**→转写、摘要、关键画面 |
| 应用 | 记忆变成万物 | **问答**：自然语言搜索知识库，基于原始资料作答并**展示引用**；**写作**：把会议和项目资料变成待办、摘要、报告、方案；**执行**：Agent 创建文件夹、移动资料、打标签、保存产出 |
| 开放 | 开放，由你掌控 | 开源（GitHub `import-ai/omnibox`，Apache-2.0）；通过 Skill 在 Codex、Claude Code 中使用；可私有化部署，配合 Ollama 离线运行 |
| 价格 | 免费开始，按需升级 | 基础版永久免费（5 GB）；高级版 ¥35/月（50 GB、顶尖模型与 Agent 2.1） |

界面事实（按截图核对，片中只画这些真实存在的元素）：左侧栏「小黑 / 通知 / 黑友社区 / 邀请有礼」，「资源 / 对话」分段切换，「回收站」；主区小黑从输入框后探头，输入框占位「随便问点什么吧」，左下「＋」「手动确认 ⌄」，右下「Agent 2.1 轻」和发送键；底部卡片「上传文档 · 让知识为你所用 · 支持文档、网页、音频和视频等多种类型」配「本地上传 / 微信助手 / 安装插件」，以及「最近更新」。

## 1. 完整提示词（交给 agent 的版本）

```text
用 Lemo-Opuscar 的「活体实机录屏 Living Screencast」风格，为小黑 OmniBox 做一支约 20 秒的中文产品介绍片。
先读 DIRECTOR.md、TECHNIQUE.md 和 styles/living-screencast/STYLE.md。风格固定，内容按下面的简报来。

【产品】小黑 OmniBox，你的 AI 知识伙伴。口号：万物变成记忆，记忆变成万物。
【要讲的三件事】
  01 记录 · 随时随地：微信、网页、随手记，随时交给小黑。
  02 理解 · 万物变成记忆：文档、图片、音视频，都变成可搜索的记忆。
  03 应用 · 记忆变成万物：一句话提问，答案带引用，还能帮你动手整理。
【主角】小黑：纯黑圆脑袋、两只尖耳朵、奶油色圆眼圈加黑瞳孔，没有嘴、没有身体（见 assets/小黑参考图.jpg）。
  在片中它是「方像素」版本：16×13 网格的硬边像素精灵，住在高清重绘的 OmniBox 界面里。
  光标是用户，小黑是软件：小黑的每个动作都要触发一次真实的界面变化。
【界面】按 assets/screenshot 用 HTML/CSS 1:1 重绘 OmniBox 网页版（不贴截图）：浅灰侧栏、白色主区、
  小黑从输入框后探头、「随便问点什么吧」、「手动确认」、「Agent 2.1 轻」、「上传文档」「最近更新」卡片。
  只画官网和截图里存在的按钮与名称，不编造功能。
【节奏】120 BPM，每小节 2 秒，所有转场、落地、弹出都卡在鼓点上：
  转场（甩镜）落在小节重拍上并配 crash，前半拍一个通鼓过门；小黑落地、条目入库、状态翻转都落在四分音符上；
  打字按十六分音符；第 15–16 秒抽掉底鼓，用军鼓滚奏蓄力；第 16 秒全乐队回归；第 18 秒最后一踩落在重拍上的大和弦。
【音乐】原创，两种分辨率：高清层（钢琴、贝斯、真鼓组、拍手、沙锤、钟琴采样）是世界，方波芯片音是小黑的声音。
  底鼓四拍、军鼓加拍手落在 2、4 拍，踩镲八分音符，贝斯切分；与字幕、画面同一条时间线。人声出现时音乐压低约 6 dB。
【配音】温暖、活泼的女声（edge-tts zh-CN-XiaoxiaoNeural，语速 +12%），一句话讲一个功能，字幕烧在毛玻璃药丸里。
【结尾】窗口收起，出现小黑 logo 和「小黑 OmniBox」；小黑按节拍逐词跳过口号「万物 → 记忆 · 记忆 → 万物」，
  最后一踩把口号点亮，下方出现「免费开始 · omnibox.pro」。
【交付】ominibox.mp4、ominibox.srt、poster.jpg、TREATMENT、源码和一键 build.sh。成片不加水印，也不加 LemoLab 署名。
```

## 2. 故事与对标

- **一句话**：藏在输入框后面的小黑「活」了过来，把散落各处的内容接住、读懂，再在一句提问里交还给你。
- **结构**：探头变身（钩子，0–4 s）→ 接住内容（记录）→ 读懂内容（理解）→ 交还答案并动手（应用）→ 口号回扣（首尾呼应：开头小黑躲在输入框后，结尾它站在口号上）。
- **对标（只学语法）**：Screen Studio 式录屏（推近光标、点击推镜、窗口浮在壁纸上）；Apple Guided Tour（一句话一个功能）；Duolingo 吉祥物动效（挤压拉伸、预备动作）。不学它们的角色、界面、配乐和镜头。
- **本片的原生招式**：界面里本来就有一个矢量小黑在探头。第 1.3 秒它碎成方像素，变成像素小黑跳出来，原处只剩一个虚线轮廓。

## 4. 小黑（像素版）设定

- 网格 16×13，纯黑 `#141414`；眼睛是 4×4 奶油色 `#FBF3E4` 圆环，中间 2×2 黑瞳孔；耳朵尖 1 像素，头底圆角。
- 表情全靠眼睛：正视、左看、右看、上看、下看、眯眼笑（∩∩）、闭眼、睁大（瞳孔缩成 1 像素）、眨眼。
- 没有手脚。移动靠「跳」：0.12 s 预备下蹲（压扁 0.28）→ 起跳拉长 → 落地压扁并回弹，扬起像素尘土。
- 待机时每拍轻压一下，随音乐呼吸。
- 道具共用同一像素网格：火花（黄 `#F5C542`）、对勾（绿）、「!」、爱心。
- 小黑只站在真实元素的上边缘（输入框、资源行、摘要卡、回答、口号文字）。位置每帧从 DOM 实测，不手填坐标。

## 5. 声音设计

| 段落 | 环境 | 拟音 | 音乐状态 |
|---|---|---|---|
| 0–2 | 极轻的房间底噪 | 眨眼「哔」、变身时的像素碎响 | 踩镲八分音符，芯片音上行琶音 |
| 2–4 | — | 落地重拍的「咚」 | 全乐队进：F 大七 |
| 4–8 | — | 每条内容入库一个「啵」（在拍上）、8-bit 跳跃与落地 | G6 → Em7，完整律动 |
| 8–12 | — | 踩行时一声「咔哒」加方波确认音；摘要弹出时的「叮」 | Am7 → F，加沙锤 |
| 12–16 | — | 键盘声（按十六分音符，带人手抖动）、发送的「嗖」、工具完成的「嘀嗒」 | G → Em，15 s 抽空蓄力 |
| 16–20.4 | — | 逐词跳的方波音符 C–E–G–C，最后一踩重低音 | 回归；18.0 Cmaj9 加钟琴 |

**静默**：15.0–16.0 抽掉底鼓，15.75–16.0 几乎全静，第一声是 16.0 的 crash。
**声音转场**：每次甩镜前半拍先起 whoosh（J-cut）；片尾大和弦一直延续到淡出（L-cut）。

## 6. 技术要点

- 画面是时间的函数：`window.render(t)`，结果确定、可逐帧渲染；Playwright 无头浏览器截 JPEG，交给 ffmpeg。
- 一条时间线（`film/film.js`）管配音起点、镜头、小黑、光标、界面状态和 `window.EV` 音效事件；`sound.py` 读 `events.json` 写配乐和混音。
- 镜头：一镜到底的「录屏软件」镜头，缩放始终 ≥ 1；只有甩镜才加各向异性动态模糊，慢推保持清晰。
- 字体：Noto Sans SC（SIL OFL 1.1）。
- 配乐采样：Salamander Grand Piano（CC BY 3.0）、MuldjordKit（CC BY 4.0）、VSCO 2 CE / VCSL / Karoryfer（CC0）；芯片音和拟音用 numpy 合成。
- 配音：edge-tts 微软神经语音（商用前请确认微软服务条款）。

## 7. 不要做

- 不编造按钮和功能，不改官方名称，不贴截图。
- 画面上不出现手，光标就是用户。
- 小黑不悬浮在空中，不挡住要读的字，不站在字幕下面。
- 画面不拉出屏幕之外。
