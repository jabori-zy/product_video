> 形式：非口播概念片，只有音乐、音效和画面文字，没有人声

## 1. 完整提示词（交给 agent 的版本）

```text

没有口播、没有人声，只用音乐、音效和画面文字。风格偏概念、炫酷，场景之间用渐变、遮罩、光效顺滑过渡，不要硬切。

【品牌】小黑 OmniBox，你的 AI 知识伙伴。口号：随时随地，万物变成记忆，记忆变成万物。
【主角】小黑：纯黑圆脑袋、两只尖耳、奶油色圆眼圈加黑瞳孔，没有嘴和身体（见 assets/小黑参考图.jpg）。
  在片中它不是卡通人物，而是一个「形状」：一个黑洞般的容器、一个遮罩、一扇门。
  它的眼睛（两个奶油色圆环）是贯穿全片的视觉母题：开场睁眼、转场的圆形光圈、片尾 logo。
【叙事】回文结构，散 → 聚 → 散：
  ① 睁眼：黑暗里睁开两只奶油色眼圈，打出「随时随地」。
  ② 万物（记录）：微信气泡、网页卡片、语音波形、PDF、照片、RSS，以及 X 帖子、YouTube 视频、知乎回答、bilibili 视频、Reddit 帖子
     在空间里漂浮，按鼓点从四面飞来：前四个每拍一个，后五个加速到每半拍一个。
  ③ 变成记忆（理解）：碎片被吸进小黑的剪影。穿过轮廓的瞬间，PDF 变成文字行，照片变成 OCR 框，波形变成转写字幕，
     最后都化成发光的节点，连成一张记忆星图。

  快闪按十六分音符（3.75 帧，取整为 4/4/4/3 帧循环）。第 15–16 秒前半抽空蓄力，第 16 秒 drop。
【音乐】原创电子乐，120 BPM，Future Bass / Melodic House 方向：开场只有氛围 pad 和心跳式低频，
  第 2 秒底鼓进入，第 6 秒加 clap 和琶音，第 10 秒全编曲，第 15 秒滤波扫频加上行噪声、抽掉底鼓，
  第 16 秒 drop，第 18 秒收在一个大和弦上并延音到结尾。音效（whoosh、impact、glitch、ding、sub drop）全部对齐转场和拍点。
【视觉】深色开场（近黑 #07080B）→ 中段是蓝紫到青的流体渐变光场 → 结尾过渡到奶油白（#FBF3E4）品牌卡。
```

## 3. 视觉系统

- **小黑的三种形态**：
  1. **眼睛**：两个奶油色圆环（外径 : 瞳孔 ≈ 1 : 0.5），是开场、转场和结尾的母题；
  2. **剪影**：参考图正面轮廓（尖耳、圆头、平底），用作 mask 和容器；
  3. **logo**：实心黑头 + 奶油眼圈，只在片尾完整出现。
  轮廓从参考图描成一条 SVG path，所有形态共用这条 path，保证形状一致。
- **色彩脚本**：近黑（S1）→ 深蓝紫光场加青色高光（S2–S3）→ 蓝紫流向琥珀（S4）→ 黑白闪（S5）→ 奶油白（S6）。整片从暗走到亮，对应「从混乱到有序」。
- **渐变光场**：3–4 个大尺寸径向渐变斑块，用 `@remotion/noise` 的 `noise2D` 驱动位置，缓慢流动，再叠一层 `mix-blend-mode: screen` 的柔光。
- **玻璃拟态卡片**：`backdrop-filter: blur(24px)`、白色 8% 底、1px 渐变描边、柔和投影；卡片里的界面元素是截图风格化后的简笔图，不贴原图。
- **粒子**：固定种子的伪随机（`random('seed')`），每个粒子有自己的相位，保证可逐帧确定性渲染。
- **颗粒与光晕**：全片覆盖一层 3% 不透明度的噪点 PNG 序列；辉光用 `filter: drop-shadow` 或 SVG `feGaussianBlur`，控制在要读的文字之外。

## 4. 音乐与音效

| 段落 | 编曲 | 音效（对齐的帧） |
|---|---|---|
| S1 0–2 s | 氛围 pad（Cmaj9）、心跳式 sub，无鼓 | 睁眼时一声低频 swell（f15）；文字出现时 glitch tick（f45） |
| S2 2–6 s | 底鼓四拍进入，pluck 琶音，贝斯跟根音 | 碎片落位的 pop / click：前四个每拍一个，后五个每半拍一个，音高逐个升高；转场前 reverse whoosh（f165） |
| S3 6–10 s | 加 clap（2、4 拍）、十六分踩镲、上行琶音 | 扫描光带的 riser（f190–240）；节点点亮的 shimmer（每拍） |
| S4 10–15 s | 全编曲：sidechain pad、主旋律 lead、贝斯切分 | 打字声（每字 4 帧）、回车 impact（f345）、卡片弹出 stab（f360 / 375 / 390 / 405）、打勾 ding |
| S5 15–16 s | 抽掉底鼓，低通扫频加上行白噪，军鼓十六分渐强，f476–479 静默 | 每个快闪词一个 glitch 小音效 |
| S6 16–20 s | drop：底鼓 + 大合成和弦 + sub drop；f540 大和弦（Fmaj9 → Cmaj9）延音到结尾 | 粒子汇聚的 whoosh-in（f480）、logo 成形的 impact（f495） |

- 调性建议 C 大调，和弦进行 **Fmaj7 – G6 – Em7 – Am7**，结尾解决到 Cmaj9。
- 音乐必须原创或使用可商用授权。可选来源：① 用 Lemo-Opuscar 的 `core/audio/sampler.py` 按上表写谱（CC0 / CC BY 采样）；② 购买可商用曲库后按 120 BPM 剪辑到 20 秒。**不要**使用来源不明的音乐。
- 音乐放在 `public/music.wav`，音效放在 `public/sfx/*.wav`；在 Remotion 里用 `<Audio>` 和 `<Sequence from={帧}>` 精确放置。
- 可选的音频驱动：用 `@remotion/media-utils` 的 `useAudioData` + `visualizeAudio`，让光场亮度和粒子大小随低频轻微跳动（幅度 ≤ 8%，别抢主体）。

## 5. Remotion 实现规格

```
concept/
├─ src/
│  ├─ Root.tsx                 // <Composition id="OmniBoxConcept" durationInFrames={600} fps={30} width={1920} height={1080}/>
│  ├─ timing.ts                // BPM=120, BEAT=15, BAR=60, beat(n), bar(n), 所有关键帧常量
│  ├─ Concept.tsx              // <TransitionSeries> 串起 6 场 + <Audio>
│  ├─ scenes/                  // S1Eyes / S2Fragments / S3Memory / S4Output / S5Flash / S6Brand
│  ├─ transitions/             // eyeIris / gradientWipe / silhouetteSwallow / dollyZoom / lightLeak / liquidBlend
│  ├─ components/              // XiaoheiPath, GlassCard, GradientField, Particles, Constellation, KineticText
│  └─ assets/xiaohei.ts        // 从参考图描出的 SVG path（头部轮廓 + 眼圈）
├─ public/ music.wav · sfx/ · fonts/NotoSansSC.ttf · fonts/Inter.ttf · grain/
└─ out/
```

- **依赖**：`remotion`、`@remotion/cli`、`@remotion/transitions`、`@remotion/noise`、`@remotion/paths`、`@remotion/shapes`、`@remotion/media-utils`、`@remotion/google-fonts`（或本地 OFL 字体）。
- **时间**：所有帧号从 `timing.ts` 导出，画面和音效共用同一组常量，不写魔法数字。
- **转场时长**：`<TransitionSeries>` 里转场会让相邻场景重叠，总时长 = 各场景时长之和 − 各转场时长之和。按下表分配，保证总长正好 600 帧、重拍落在转场中点：

  | 场景 | S1 | S2 | S3 | S4 | S5 | S6 |
  |---|---|---|---|---|---|---|
  | 场景帧数 | 67 | 136 | 138 | 168 | 43 | 124 |
  | 进入下一场的转场 | 14 | 18 | 18 | 18 | 8 | — |
  | 场景起点（帧） | 0 | 53 | 171 | 291 | 441 | 476 |
  | 转场中点（帧） | 60 | 180 | 300 | 450 | 480 | — |

  （场景帧数之和 676 − 转场之和 76 = 600。算法：转场占用前一场最后 d 帧；想让中点落在重拍 T 上，下一场的起点就是 T − d/2。实现后用 `npx remotion still` 核对这 5 个重拍帧。）
- **转场实现**：用 `@remotion/transitions` 自定义 `presentation`（接收 `presentationProgress`）：
  - `eyeIris`：`clip-path: circle()`，半径从瞳孔大小长到对角线长度，边缘加 20 px 羽化光环；
  - `gradientWipe`：`mask-image: linear-gradient(...)`，渐变位置随进度移动，带 15% 宽的柔边；
  - `silhouetteSwallow`：小黑 path 做 `<mask>`，`scale` 从 40 缩到 1；
  - `dollyZoom`：前一场 `scale` 1→6 加模糊，后一场 `scale` 0.6→1 淡入；
  - `lightLeak`：叠一层奶油色到琥珀色的径向渐变，用 `screen` 混合，峰值 0.9；
  - `liquidBlend`：SVG `feTurbulence` + `feDisplacementMap`，位移强度按正弦包络变化。
  - 缓动统一用 `Easing.bezier(0.65, 0, 0.35, 1)` 或 `springTiming({ config: { damping: 200 } })`。
- **动效原则**：主体运动用 `spring()`，数值映射用 `interpolate(..., { extrapolateLeft: 'clamp', extrapolateRight: 'clamp' })`；禁止用 `Math.random()`，一律用 `random(seed)`；每个元素都要有预备 → 动作 → 余势，至少一处明显加速（S5）和一处呼吸（S6 最后 1 秒）。
- **性能**：粒子控制在 400 个以内；模糊只在转场中施加；用 `npx remotion render OmniBoxConcept out/ominibox-concept.mp4 --codec h264 --crf 18 --concurrency 6` 渲染。
