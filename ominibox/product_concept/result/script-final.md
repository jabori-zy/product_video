# 小黑 OmniBox · 产品介绍片 · Final（≈126.4 s）

> 成片：`../demo/out/ominibox_product_video_final.mp4`（`npm run render:final -- final`）。
> 内容、镜头顺序、文案与 `script-v2.md` 相同；下面只记录相对 v2 的优化。v2 的分镜表仍是画面内容的依据，时间整体顺延（见文末时间表）。

## 1. 节奏：转场卡在小节线上

- v2 的段落转场都不在音乐重拍上（离小节线 0.2–3.9 拍不等），甩镜、光带和镲片各响各的。
- `src/pace.ts` 新增 `SNAP`：每个转场前那段「停留」的放慢倍数自动微调，让转场落在最近的小节线上（120 BPM，一小节 2 s，从全乐队进入 BAND 起算）。
- 两段手机插段改成整 8 小节（16 s，`src/appTimeline.ts` 的 `len / dur`），画面按 15.25/16、15.2/16 略放慢约 5%，插段首尾也在小节线上。
- 声音事件表经 `insertScale` 同步换算，`npm run audio` 自动重新对齐。

## 2. 音乐：按段落编曲（`audio/plans.ts`）

## 3. 母带

- 合成里的限幅器顶到 −2 dBFS；`tools/render-final.mjs` 合成时用两遍 loudnorm（线性增益）把成片校到 **−14 LUFS、真峰值 ≤ −1.5 dBTP**（v2 是 −13.3 LUFS、−0.1 dBTP，转码平台会削波）。

## 4. 画面

- **标题垫底**：叠在界面上的大字（D「自动打标签」「⌘J，一搜就到」，E 三条）加磨砂深色底板（`Caption` 的 `plate`），白字压在白色知乎页上也看得清。
- **口号配色统一**：D「万物变成**记忆**」、E「**记忆**变成万物」里的「记忆」与结尾一样用品牌蓝 `#7FB0FF`；口号背后彻底压黑，不再透出界面残影。
- **镜头推近**（原来大量 1:1 全景，字只有 13–15 px）：
  - A：发送后推近对话 1.25×；
  - D：⌘J 搜索框放大到 1.3×；
  - E：输入周报指令、Agent 指令时推近输入框 1.5×，周报生成时跟着内容 1.3×，保存时拉回全景看资源树；
  - C+：录音面板、确认对话框、「更多方式」推近到 1.9×；
  - E+：读周报、看回答 1.75×，输入追问、引用来源面板 1.9×。
- **E+ 定格帧去残影**：「资料变成周报」提前 0.15 s 收掉，插段里笔记本屏幕上不再挂着半透明标题。
- **结尾**：光带一过就出第一个词（不留黑场）；行动按钮改成品牌蓝胶囊「免费开始 →」+ `omnibox.pro`，弹出带音效；结尾多停 1.2 s，并多眨一次眼再淡出。
