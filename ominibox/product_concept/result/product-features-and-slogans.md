## 2. Feature Overview: Four Parts Matching the Video

### 1. Capture · Anytime, Anywhere

| Feature | One-line description | Short slogan |
|---|---|---|
| Browser extension | A floating card at the top right saves the entire page with "Save to Xiaohei"; hold ⌥ to select a "Specific area"; the text-selection menu also offers "Save to Xiaohei" | ★ **One click. A whole page or just a selection.** |
| Social content / online video | Zhihu, Xiaohongshu, X, Reddit, Douyin, and Bilibili; videos automatically receive summaries, chapters, and key frames | ★ **Zhihu, Xiaohongshu, Bilibili—save them all.** |
| WeChat assistant / QQ assistant / WeChat ClawBot | Send text, voice messages, images, files, links, and merged forwards directly to Xiaohei; add tags with `#tags` | ★ **Forward it to Xiaohei. Saved.** |
| Mobile app | iOS / Android / PWA; recording, text, photo, and link entry points; "Share to Xiaohei" in the system share menu | ★ **Capture a thought. Keep the inspiration.** |
| RSS subscription folders | Blogs, news, and podcasts; new content is saved automatically | ★ **Subscribe. New content saves itself.** |
| Local upload | PDF, Word, PPT, images, audio, and video; drag them into the sidebar | **Just drag it in.** |
| Shortcuts | iOS / macOS: file uploads, quick text notes, and quick voice notes | **A quick note, in a sentence.** |

> ★ Section headline: **Anytime, anywhere. Leave it to Xiaohei.**

### 2. Understand · Everything Becomes Memory

| Feature | One-line description | Short slogan |
|---|---|---|
| Document parsing | Turn PDF / Word / PPT files into editable, searchable documents | ★ **Documents → Full-text search** |
| Image parsing | OCR turns scans into text; photos receive semantic summaries | ★ **Images → Text recognition** |
| Audio and video parsing | Transcripts, summaries, chapters, and key frames | ★ **Audio & video → Transcripts and summaries** |
| Web clipping | Turn webpage content into editable documents linked to their sources | **Webpages → Traceable documents** |
| Automatic tags | Tag resources automatically when they are saved | ★ **Automatically tagged** |
| Smart folders | Automatically collect resources by title, tags, content, time, and other rules without moving the originals | **Set the rules. Let it organize.** |
| Smart search | Keyword and semantic search; open with ⌘J; matching text is highlighted | ★ **⌘J. Search. Found.** |
| Editing and versions | Read / edit modes, edit history, wide view, and export | **Edit it. Trace it back.** |

> ★ Section headline: **Everything becomes memory.**

### 3. Apply · Memory Becomes Everything

| Feature | One-line description | Short slogan |
|---|---|---|
| Knowledge-base Q&A | Ask in natural language; answers are based on original materials, and citations jump to the exact source line | ★ **Answers with sources. Every time.** |
| Deep thinking / web search | Low, medium, high, and maximum reasoning effort; optionally supplement with web results | **Think deeper. Search wider.** |
| AI writing | Turn materials into summaries, reports, emails, and proposals, around 5–6k Chinese characters per response; "Save to personal space" | ★ **Turn your sources into a weekly report.** |
| Agent 2.1 execution | Create folders, move resources, add tags, and save webpages; request "Approve" before making changes | ★ **One request. Everything organized.** |
| Xiaohei sidebar | Open Xiaohei on the right side of any resource page and continue chatting | **Read and ask, side by side.** |
| Chat history | The "Chats" tab groups conversations by today, past 7 days, and month; searchable | **Every conversation counts.** |

> ★ Section headline: **Ask · Write · Act** → **Memory becomes everything.**

### 4. Share and Collaborate · Open and in Your Control

| Feature | One-line description | Short slogan |
|---|---|---|
| Share links | Configure login requirements, password protection, expiration, and whether "AI Q&A" is available | ★ **Share your knowledge. Take AI along.** |
| Team spaces | "Personal" and "Team" spaces; invite members by link or email | ★ **A second brain for you. A knowledge base for your team.** |
| All platforms | Web, browser extension, iOS, Android, WeChat, and QQ | ★ **Every platform. One Xiaohei.** |

| Skill / API | Use Xiaohei from Claude Code and Codex; open API | ★ **Your agent can use Xiaohei, too.** |
| Free | The basic plan is free forever; upgrade as needed | ★ **Start for free.** |

> ★ Section headline: **Open. In your control.**
