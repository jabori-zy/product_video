# 参考视频特点

> 三支参考片都在 16–19 秒之间，60 fps，没有口播，只有音乐和画面文字。以下按 0.25–0.5 秒抽帧逐段分析。

---

## 1. 产品介绍镜头转换参考视频（LuxAlgo，17.9 s，1920×1080）

**一句话**：深色 UI 被当作「实拍物体」来拍。虚拟摄像机一直在运动（3D 倾斜、推近、甩镜），配合浅景深和运动模糊，镜头之间几乎没有硬切。

| 时间 | 画面 | 镜头 / 转场 |
|---|---|---|
| 0–1.5s | 订单簿、K 线图局部 | 透视倾斜的平面 UI 慢推，画面边缘虚化 |
| 1.5–2.5s | 工具栏「Indicators」、九宫格布局按钮 | 超近景特写加大角度倾斜，光标点击，背景强虚化 |
| 2.5–3.5s | 多面板布局 → 环形菜单 | 拉远露出全貌，再推进到环形菜单 |
| 3.5–4.2s | 环形菜单高亮扇区 | **甩镜加运动模糊**：镜头绕盘面旋转，近乎 3D 物体 |
| 4.2–5.5s | Ray → Rectangle 扇区 | 高亮扇区跟随光标转动，标签放大 |
| 5.5–6s | 图表上画出矩形 | 直接切回图表，矩形画出（一个动作的结果） |
| 6–7.5s | 「+ Panels」按钮 → Watchlist 面板 | 按钮特写 → 面板滑出，画面一闪变暗 |
| 7.5–10.5s | Indicators → LIBRARY → LuxAlgo → 指标卡片 | 「点哪推哪」：每次点击后镜头推向被点元素，下一个界面从这里展开 |
| 12–15s | AI 输入框「Give me a signal…」→ Thinking… → AI 回答加图表信号 | 输入框特写，拉远成三栏全景，左边 AI 回答流式出现 |
| 15–17s | 全景，「Built for you.」 | 在 UI 上逐词叠出斜体白字，镜头缓慢后退 |
| 17–17.9s | LuxAlgo logo | 灰白径向渐变背景，logo 逐字出现 |

**可借鉴的点**
- **镜头语言**：UI 平面带 `rotateX/rotateY` 透视，摄像机持续缓推，不出现静止画面。
- **特写与全景交替**：按钮 / 菜单用超近景（放大 3–5 倍，景深虚化），结果用全景展示。
- **点击驱动转场**：光标点一下 → 镜头推向点击点 → 新界面从这点展开，因果关系一目了然。
- **甩镜加运动模糊**：用来串联两个不同界面，速度很快（约 0.3 s）。
- **深色 UI 加高饱和强调色**（蓝色扇区、红绿 K 线），暗部占大部分画面。
- **收尾**：全景 UI 叠一句短 slogan，然后切到品牌 logo。

## 2. 产品功能介绍参考视频（Infinity AI V3，16.5 s，1920×1080）

**一句话**：黑、白、橙三色。在大字排版和极简白底 UI 之间来回切换，节奏像发布会快闪；文字本身就是主角。

| 时间 | 画面 | 镜头 / 转场 |
|---|---|---|
| 0–1.5s | 黑底，小号白字「Introducing」，细线圆环 | 极简开场，细线圆缓慢旋转 |
| 1.5–3s | 橙色渐变球体涨满全屏，「Based」 | **色块吞屏转场**：渐变球体扩张，背景从黑变橙 |
| 3–4s | 巨大的「V3」，橙色渐变字，两侧是橙球 | 大字冲击 |
| 4–5s | 白底「See what moves the market」 | 硬切到白底，文字带轻微 3D 透视漂移 |
| 5–7.5s | 宏观日历卡片（Nonfarm / PPI / Jobless）→ 完整列表 | 卡片特写 → 拉远成列表，中间有一条红色「NOW」时间线 |
| 7.5–10.5s | NEWS → Financial Juice → 新闻列表 | **打字机加光标**逐字出现，列表逐行淡入 |
| 10.5–12s | 底部 Tab「Macro / Traders / Markets / For You」加 ∞ 图标 | 选中态在 Tab 间滑动，其他 Tab 淡出，只留图标 |
| 12–12.5s | 白底中心红色 ∞ 小圆点 | 所有元素收成一个点 |
| 12.5–14.5s | 「Explore」「smarter」逐词出现 | **小点爆开成橙色模糊球体**转到黑底，橙色光带划弧，每个词单独占一帧画面 |
| 14.5–16.5s | 「with Infinity AI」加 ∞ logo | 光带收成 logo 圆环 |

**可借鉴的点**
- **配色克制**：黑、白加一个品牌强调色（橙），强调色只用在光球、光带、logo 上。
- **逐词大字**：slogan 拆成单词，一拍一个词，字号很大，居中。
- **形状转场**：圆点、球体、光带作为转场载体（点 → 球 → 满屏），比遮罩更有品牌感。
- **白底 UI 段落**：UI 卡片无边框、大留白、轻阴影，用来讲具体功能。
- **打字机效果**展示标题和搜索内容。
- **收束到图标**：UI 元素逐步淡出，只剩品牌图标，再从图标切到结尾。

## 3. 组件切换效果参考视频（Motion Study，18.8 s，2048×1080）

**一句话**：一个黑色胶囊组件在米白画布中央不断「变形」。按钮 → 加载圈 → 对勾 → 播放器 → 进度条 → 开关 → 分段控件 → 数据卡片，全程一个元素，没有剪辑。

| 时间 | 组件变化 |
|---|---|
| 0–1s | 「Generate」按钮 → 被点击 → 收缩成圆 → 加载转圈 → 对勾 |
| 1–2s | 对勾圆拉伸成胶囊（音频波形）→ 展开成播放器卡片（封面渐变、标题、进度条） |
| 2–3.8s | 播放器点击播放，拖动进度条 |
| 3.8–5s | 卡片压扁成音量条，拖动音量 |
| 5–6s | 音量条收缩成开关 Toggle，点击切换黑白 |
| 6–7s | 开关拉长成 Day / Week / Month 分段控件，选中块滑动 |
| 7–9.5s | 分段控件长成白色数据卡片：数字滚动（72,060 → 84,320），折线画出，悬浮提示跟随 |
| 9.5–11.5s | 卡片缩小成下拉菜单，选中项 |
| 12–13s | 菜单收回成「Generate」按钮（首尾呼应，可循环） |
| 13–18.8s | 停在数据卡片上展示 hover 交互 |

**可借鉴的点**
- **共享元素变形（Shared-element morph）**：前一个组件的外框（圆角、宽高、颜色）用 spring 插值变成下一个组件，内容交叉淡入淡出。这是 Remotion 最容易做得高级的效果。
- **弹性物理**：每次变形有轻微回弹（spring damping 约 12–15），点击时组件先缩到约 0.95 再弹回。
- **光标是叙事主体**：真实的 macOS 光标，移动轨迹带缓动，点击时有按压反馈。
- **数字滚动、折线绘制**：用 `interpolate` 驱动数字滚动和 SVG `strokeDashoffset`。
- **极简画布**：米白底（约 #EDEDEA），黑色组件，没有任何装饰。
- **首尾呼应**：从按钮开始，回到按钮结束。

## 4. 综合：本片要从三支参考片里拿什么

| 来源 | 借用 | 在 OmniBox 片中的用法 |
|---|---|---|
| 参考 1 | 3D 透视加摄像机运动、点击驱动转场、甩镜运动模糊、特写全景交替 | 浏览器、知乎页面、OmniBox 深色界面都放在 3D 空间里拍；插件按钮、「保存到小黑」用超近景特写 |
| 参考 2 | 黑白加一个强调色、逐词大字、圆点或球体转场、打字机效果 | 品牌色用小黑的黑和奶油白（#F5EFE3），强调色用 OmniBox 蓝；slogan 逐词打出；小黑的**眼圈**代替 ∞ 圆点做形状转场 |
| 参考 3 | 共享元素变形、spring 回弹、光标叙事 | 「保存到小黑」按钮 → 加载 → 对勾 → 变成资源卡片飞进侧边栏；输入框变形成回答卡片 |

**节奏建议**：参考片平均 0.5–1.5 s 换一次画面，大段落 3–5 s。45 秒的片子大约安排 8–10 个段落、30 个以上画面变化，不能有静止超过 1.5 s 的画面。
