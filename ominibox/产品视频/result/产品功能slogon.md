## 二、功能总览（四段式，对应成片结构）

### 1. 记录 · 随时随地

| 功能 | 一句话说明 | Slogan（短） |
|---|---|---|
| 浏览器插件 | 网页右上角浮出卡片，「保存到小黑」一键收藏整页；按住 ⌥ 框选「指定区域」；划词菜单「保存到小黑」 | ★ **一键收藏，整页或选区** |
| 社交内容 / 在线视频 | 知乎、小红书、X、Reddit、抖音、B 站；视频自动生成摘要、章节、关键画面 | ★ **知乎、小红书、B 站，统统收下** |
| 微信助手 / QQ 助手 / 微信 ClawBot | 文字、语音、图片、文件、链接、合并转发，直接发给小黑；`#标签` 顺手打标 | ★ **转发给小黑，就存好了** |
| 移动端 App | iOS / Android / PWA；录音、文字、拍照、链接四个入口；系统分享菜单「分享到小黑」 | ★ **随手一记，灵感不丢** |
| RSS 订阅文件夹 | 博客、新闻、播客，新内容自动入库 | ★ **订阅自动入库** |
| 本地上传 | PDF、Word、PPT、图片、音视频；拖到侧边栏即可 | **拖进来就行** |
| 快捷指令 | iOS / macOS：文件上传、文字闪记、语音闪记 | **一句话闪记** |

> ★ 本段大字：**随时随地，交给小黑**

### 2. 理解 · 万物变成记忆

| 功能 | 一句话说明 | Slogan（短） |
|---|---|---|
| 文档解析 | PDF / Word / PPT 转成可编辑、可搜索的文档 | ★ **文档 → 全文可搜** |
| 图片解析 | 扫描件 OCR 成文字，照片生成语义摘要 | ★ **图片 → 文字识别** |
| 音视频解析 | 转写、摘要、章节、关键画面 | ★ **音视频 → 转写摘要** |
| 网页剪藏 | 网页正文转成可编辑、可追溯的文档 | **网页 → 可追溯文档** |
| 自动标签 | 入库自动打标签 | ★ **自动打标签** |
| 智能文件夹 | 按标题、标签、正文、时间等规则自动汇总，不移动原文件 | **规则一设，自动归类** |
| 智能搜索 | 关键词加语义搜索，⌘J 唤起，命中处高亮 | ★ **⌘J，一搜就到** |
| 编辑与版本 | 阅读 / 编辑模式、编辑历史、宽屏、导出 | **可编辑，可回溯** |

> ★ 本段大字：**万物变成记忆**

### 3. 应用 · 记忆变成万物

| 功能 | 一句话说明 | Slogan（短） |
|---|---|---|
| 知识库问答 | 自然语言提问，基于原始资料作答，点引用跳回原文那一行 | ★ **有问必答，句句有出处** |
| 深度思考 / 联网搜索 | 思考强度分轻、中、高、最大；可联网补充 | **想得深，搜得广** |
| AI 写作 | 把资料写成总结、报告、邮件、方案，单次 5–6k 字，可「保存至个人空间」 | ★ **资料变成周报** |
| Agent 2.1 执行 | 建文件夹、移动资料、打标签、收藏网页；改动前先请求「同意」 | ★ **一句话，帮你整理好** |
| 侧边栏小黑 | 在任意资源页右侧打开小黑，继续对话 | **边看边问** |
| 对话历史 | 「对话」页签按今天 / 过去 7 天 / 月份归档，可搜索 | **每次对话都算数** |

> ★ 本段大字：**问答 · 写作 · 执行** → **记忆变成万物**
